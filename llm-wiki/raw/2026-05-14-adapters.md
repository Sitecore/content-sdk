# Adapters (snapshot)

Adapters provide **environment-specific** implementations for **plugins** (browser vs server: cookies, request/response, fetching). In analytics, adapters implement **`AnalyticsAdapter`**, extending **`PluginAdapter`** from `@sitecore-content-sdk/core`.

Example shape (per doc): `getClientId`, `setClientId`, `location.getSearchParams`. Passed into plugins at init so plugins stay environment-agnostic. Example: `initContentSdk` with `analyticsPlugin({ adapter: analyticsBrowserAdapter(), options: { enableCookie: true } })` and `eventsPlugin()`.
