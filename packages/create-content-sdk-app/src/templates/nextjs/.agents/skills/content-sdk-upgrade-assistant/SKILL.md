# Upgrade assistant (Pages Router)

**Detail:** [AGENTS-router-specifics.md](../../docs/AGENTS-router-specifics.md)

## When

- Bumping SDK package versions or migration from older SDK

## Rules

- Check Content SDK CHANGELOG and upgrade guides
- Run `npm run build` after upgrade

## Stop

- Stop if upgrade requires undocumented breaking env or config changes without user confirmation

Docs: [Content SDK](https://doc.sitecore.com/sai/en/developers/content-sdk/sitecore-content-sdk-for-sitecoreai.html).
