# @sitecore-content-sdk/nextjs-templates

Next.js scaffolding templates and initializers for the Sitecore Content SDK. Consumed by [`create-content-sdk-app`](../../packages/create-content-sdk-app) to generate Next.js head applications.

This package owns the `nextjs`, `nextjs-app-router`, and `nextjs-app-router-cache-components` templates, their initializers, and the `@sitecore-content-sdk` dependency versions that scaffolded apps receive.

[Documentation](https://doc.sitecore.com/xmc/en/developers/content-sdk/index.html)
