# Multisite management (Angular)

**Detail:** [AGENTS-angular-specifics.md#multisite](../../docs/AGENTS-angular-specifics.md#multisite)
**Read first:** `src/server.ts`, `.sitecore/sites.json`

## When

- Multisite routing, site resolution, or `sites.json` changes

## Rules

- `createMultisiteMiddleware` resolves the site in a fixed order: `sc_site` query → `sc_site` cookie → hostname → `defaultSite`, and writes it to `req.scParams`
- It must run **before** bot tracking, redirects and personalize, all of which read the resolved site
- Loaders read the site with `getSiteName(context)` — never hardcode a site name
- The site list comes from `.sitecore/sites.json` (generated by `generateSites()`); do not hardcode or hand-edit it
- Site is part of the loader cache key — do not remove it
- Cross-origin setups may not send the `sc_site` cookie; use `?sc_site=` or `SameSite=None; Secure`

## Stop

- Stop if changing middleware order without explicit approval
- Stop if a link or loader would hardcode a site

Docs: [Content SDK for Angular](https://doc.sitecore.com/sai/en/developers/content-sdk/angular/10/sitecore-content-sdk-for-angular.html).
