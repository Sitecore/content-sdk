# @sitecore-content-sdk/angular-templates

Angular scaffolding templates and initializers for the Sitecore Content SDK. Consumed by [`create-content-sdk-app`](../../packages/create-content-sdk-app) to generate Angular head applications.

This package owns the `angular` template, its initializer, and the `@sitecore-content-sdk` dependency versions that scaffolded apps receive.

[Documentation](https://doc.sitecore.com/xmc/en/developers/content-sdk/index.html)
